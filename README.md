# Henry Gichunge — Personal Brand Website

Ideas. Education. Innovation.

## Stack
React, TypeScript, Vite, Tailwind CSS v4, React Router, Lucide icons.
Cloudflare Workers, Hono, D1 and R2 are added in later batches.

## Run locally
Requires Node.js 20.19 or newer.

    npm install
    npm run dev

Open http://localhost:5173

## Build
    npm run build

## Editing content (Batch 01)
All text, projects and links are in `src/data/site.ts`.
To use your own photo, put it in `public/images/` and set
`portraitSrc` in `src/data/site.ts` (e.g. "/images/henry.jpg").
